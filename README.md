# IntelliStudy

IntelliStudy is a student planner that brings assignments, exams, and study sessions into one calendar.

## Problem
Course deadlines are spread across different platforms, making it difficult to track work and plan study time.

## Planned MVP
- Add, edit, and delete assignments, exams, and study sessions.
- View tasks and deadlines on a calendar.
- Mark tasks as completed.
- Save tasks locally between visits.

## Planned Tech Stack
- JavaScript, React, HTML, and CSS
- Vite and npm
- FullCalendar
- React DatePicker
- Lucide React
- Browser localStorage for JSON task storage
